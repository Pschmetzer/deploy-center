# Contributing

- `bash tests/script-tests.sh` and `bash tests/app-tests.sh` must pass; `./build.sh` must build.
- No personal project names, team IDs, domains or paths in commits (the repo is public).
- Texts are English and German: use `L("English", "Deutsch")`.
- Nothing may start a build without an explicit click or a command with `--yes`.
