Deploys in Folge ohne Fehlschlag: deine Serie

deploys streak zählt je Projekt, wie viele Deploys in Folge ohne Fehlschlag live gingen: die Serie jetzt und die längste. Es zeigt auch die Zahl der Deploys, die Fehlschläge und das Datum des letzten Fehlschlags. Es liest nur das Journal.

Zuletzt aktualisiert am 23. November 2026 · von Patrick Schmetzer, Autor von Deploy Center

English version

1. Aufrufen

deploys streak                       # letzte 90 Tage
deploys streak --days 30 --project web
deploys streak --json

Ein ausgedachtes Beispiel (die Ausgabe der CLI ist englisch):

Deploys in a row without a failure, last 90 days
  web (Vercel): 2 now, longest 2 (2 deploys, 1 failed, last failure 2026-11-21)
  api (Render): 0 now, longest 0 (0 deploys, 1 failed, last failure 2026-11-22)

2. Wie gezählt wird

  • now (jetzt): Deploys seit dem letzten Fehlschlag dieses Projekts. Ein Fehlschlag setzt auf 0 zurück.
  • longest (längste): die beste Serie im Zeitraum.
  • Ein Projekt mit einem Fehlschlag und keinem Deploy danach, wie api oben, zeigt 0.

Eine lange Serie ist nur so gut wie die Deploys dahinter. Drei Deploys in Folge sind wenig, 40 nicht.

3. Wofür es gut ist

  • Als schneller Check am Montag: welches Projekt ist zuletzt gescheitert?
  • Als Zahl für eine README, eine Statusseite oder einen Bericht. --json liefert sie je Projekt, siehe die Statusseiten-Anleitung.
  • Neben der Erholungszeit: wie oft es kaputtgeht, und wie lange das Beheben dauert.

Jede Zahl kommt aus dem Journal auf deinem Mac. Kein Netz, kein Aufruf beim Anbieter, nichts wird gestartet.

Fragen

Was zählt als Fehlschlag?

Ein Deploy mit dem Ergebnis failed im Journal. Ein Rollback oder ein erzwungener Start ist für sich kein Fehlschlag.

Warum ist die Serie 0 bei einem Projekt, das läuft?

Der letzte Journal-Eintrag im Zeitraum ist ein Fehlschlag, oder nach dem letzten Fehlschlag gab es keinen Deploy. Deploye erneut, dann zählt es.

Ändert ein längerer Zeitraum das Ergebnis?

Ja. --days 365 schaut weiter zurück, die längste Serie kann also größer werden. Die Serie jetzt bleibt gleich.

Geht es ohne Netz?

Ja. Es liest das lokale Journal.
