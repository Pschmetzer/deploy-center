Deploy auf Abruf: Hook, CLI, Actions oder Deploy Center

Sind Push-Builds aus, brauchst du einen Weg zum Ausliefern. Ein Deploy-Hook ist der kleinste, der Button oder die CLI des Anbieters braucht nichts Zusätzliches, GitHub Actions ergänzt Auslöser wie ein Label, und Deploy Center ergänzt eine Liste dessen, was wartet, CI- und Fenster-Prüfungen und einen Rollback.

Deploy-Hook

Ein Deploy-Hook ist eine URL, die einen Build startet, wenn du sie aufrufst. Er funktioniert bei jedem Anbieter, der einen hat, und braucht keine Software. Die URL ist ein Geheimnis: Wer sie hat, kann einen Build starten. Er sagt nichts darüber, was wartet, und hat keine eigenen Prüfungen. Siehe Deploy-Hooks für jeden Anbieter (englisch).

Button oder CLI des Anbieters

Render hat Manual Deploy, Vercel hat seine CLI; jeder Anbieter hat etwas Eigenes. Das ist die richtige Wahl für ein oder zwei Projekte bei einem Anbieter. Bei mehreren Projekten bei mehreren Anbietern besuchst du mehrere Dashboards, um herauszufinden, was zurückliegt.

GitHub Actions

Ein Workflow kann einen Hook aufrufen, wenn ein Pull Request ein Label bekommt, oder einmal am Tag deployen. Er läuft ohne deinen Mac und lässt sich als Code prüfen. Die Prüfungen schreibst du selbst, und geplante Workflows stoppen nach 60 Tagen ohne Aktivität im Repository. Siehe Deploy to Vercel from GitHub Actions (englisch).

Deploy Center

Deploy Center listet die wartenden Commits und Pull Requests je Projekt, deployt, wenn du klickst oder einen Befehl mit --yes ausführst, und bietet die Prüfungen, die die anderen Wege dir überlassen: CI muss grün sein, ein Deploy-Freeze, ein automatischer Rollback. Es ist eine Mac-App und eine Bash-CLI; die App selbst braucht macOS 15 oder neuer, die CLI läuft auch unter Linux und in CI.

Du kannst sie mischen. Deploy Center ruft auch Deploy-Hooks für Anbieter auf, die nichts anderes bieten, und die CLI läuft in einem GitHub-Actions-Workflow.

Fragen

Was ist die kleinste Einrichtung?

Ein Deploy-Hook und curl. Er hat keine Prüfungen und zeigt nichts darüber, was wartet.

Kann ich Deploy Center ohne Mac nutzen?

Die CLI ist Bash und läuft unter Linux, WSL und in CI. Die App und die Widgets brauchen macOS.

Ist ein Deploy-Hook weniger sicher?

Er ist wie jede geheime URL: Halte ihn aus dem Repository und aus Logs heraus und erneuere ihn, wenn er durchsickert.

Was nehme ich bei vielen Projekten?

Ein Werkzeug, das auflistet, was bei allen wartet; bei den anderen Wegen besteht der Aufwand darin, jedes Projekt einzeln anzusehen.

Du nutzt Vercel oder Render?

Deploy Center schaltet Auto-Deploy bei Vercel und Render mit einem Klick ab, Netlify und andere Hosts sind optional, und es deployt, was sich geändert hat, wenn du es entscheidest. Kostenlos und Open Source für macOS.
