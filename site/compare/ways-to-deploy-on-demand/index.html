Deploy on demand: hook, CLI, Actions or Deploy Center

Once push builds are off you need a way to ship. A deploy hook is the smallest, the host's own button or CLI needs nothing extra, GitHub Actions adds triggers like a label, and Deploy Center adds a list of what waits, CI and window checks, and rollback.

Deploy hook

A deploy hook is a URL that starts a build when you call it. It works on any host that has one, and needs no software. The URL is a secret: anyone who has it can start a build. It tells you nothing about what is waiting and has no checks of its own. See deploy hooks for any host.

The host's button or CLI

Render has Manual Deploy and Vercel has its CLI; each host has its own. This is the right choice for one or two projects on one host. With several projects on several hosts you visit several dashboards to find out what is behind.

GitHub Actions

A workflow can call a hook when a pull request gets a label, or deploy once a day. It runs without your Mac and you can review it as code. You write the checks yourself, and scheduled workflows stop after 60 days without activity in the repository. See Deploy to Vercel from GitHub Actions.

Deploy Center

Deploy Center lists the commits and pull requests waiting per project, deploys when you click or run a command with --yes, and offers the checks the other ways leave to you: CI must be green, a deploy freeze, an automatic rollback. It is a Mac app and a bash CLI, so the app itself needs macOS 15 or later; the CLI also runs on Linux and in CI.

You can mix them. Deploy Center also calls deploy hooks for hosts that offer nothing else, and the CLI runs inside a GitHub Actions workflow.

Questions

Which is the smallest setup?

A deploy hook and curl. It has no checks and shows nothing about what waits.

Can I use Deploy Center without a Mac?

The CLI is bash and runs on Linux, WSL and in CI. The app and the widgets need macOS.

Is a deploy hook less safe?

It is the same as any secret URL: keep it out of the repository and logs, and rotate it if it leaks.

Which should I pick for many projects?

A tool that lists what waits across all of them, since the cost of the other ways is looking at each project in turn.

Use Vercel or Render too?

Deploy Center turns off auto-deploy on Vercel and Render in one click, Netlify and other hosts opt-in, and deploys what changed when you decide. Free and open source for macOS.
