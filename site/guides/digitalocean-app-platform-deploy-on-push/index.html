How to stop DigitalOcean App Platform deploying on every push

Every component built from a repo has an Autodeploy switch, which is deploy_on_push in the app spec. Set it to false on each component and save the spec. Pushes then build nothing, and you deploy when you decide.

Last updated 16 November 2026 · by Patrick Schmetzer, author of Deploy Center

App Platform builds and deploys a component every time you push to the branch it watches. Each build uses build minutes and each deploy restarts the app.

1. In the app spec

In the app spec, each service, static site, worker, job or function built from a github, gitlab or bitbucket source carries deploy_on_push:

services:
  - name: web
    github:
      repo: my-org/my-repo
      branch: main
      deploy_on_push: false

For an image from the DigitalOcean container registry the flag is image.deploy_on_push.enabled. The same switch is the Autodeploy setting of the component in the control panel.

Trade-offs. The API cannot change one switch: PUT /v2/apps/{id} takes the whole spec. Read the spec first and send it back with only the flags changed, or edit it in the control panel, so you do not overwrite anything else.

2. Deploying by hand

Create a deployment in the control panel, or with POST /v2/apps/{id}/deployments and force_build: false. App Platform takes the newest commit of each component's branch and reuses a cached build where it can.

DigitalOcean in Deploy Center

Deploy Center supports App Platform as an opt-in host: deploys providers enable digitalocean, then pbpaste | deploys digitalocean set-key with a token that may read and update apps. deploys digitalocean autodeploy-off <app> reads the spec, sets deploy_on_push to false on every component, saves the old spec in your config folder, sends the spec back and checks the answer. Details: the DigitalOcean provider docs.

Questions

What turns off autodeploy on DigitalOcean App Platform?

deploy_on_push set to false on the component source in the app spec, or the Autodeploy switch of the component in the control panel.

Can the API change just one component?

No. PUT /v2/apps/{id} takes the whole spec, so read it first and send it back with only the flags changed.

How do I deploy by hand?

Create a deployment in the control panel, or POST /v2/apps/{id}/deployments with force_build set to false.

Does Deploy Center support DigitalOcean?

Yes, as an opt-in host. It sets deploy_on_push to false on every component and keeps the previous spec.

Use Vercel or Render too?
