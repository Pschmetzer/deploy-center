Skip Vercel previews for Dependabot and AI agents

Set this as the Ignored Build Step: bash -c 'case "$VERCEL_GIT_COMMIT_REF" in dependabot/*|renovate/*|claude/*|cursor/*) exit 0;; *) exit 1;; esac'. Exit 0 skips the build, exit 1 builds it. Change the prefixes to the ones your tools use.

Last updated 27 November 2026 · by Patrick Schmetzer, author of Deploy Center

Dependabot, Renovate and coding agents push to their own branches, and each push builds a preview in every connected project. Nobody looks at most of them. A skipped build is cancelled before the build command runs.

1. The script

bash -c 'case "$VERCEL_GIT_COMMIT_REF" in dependabot/*|renovate/*|claude/*|cursor/*) exit 0;; *) exit 1;; esac'

VERCEL_GIT_COMMIT_REF is the branch of the commit. Branches from people, and production, still build.

2. Where to put it

In the project, Settings → Git → Ignored Build Step, or as ignoreCommand in vercel.json:

{
  "ignoreCommand": "bash -c 'case \"$VERCEL_GIT_COMMIT_REF\" in dependabot/*|renovate/*|claude/*|cursor/*) exit 0;; *) exit 1;; esac'"
}

3. Agents that push to your own branches

If an agent pushes to branches without a fixed prefix, ask it to use one, or skip on a marker in the commit message: VERCEL_GIT_COMMIT_MESSAGE holds it, and only the newest commit of a push is checked. See the Ignored Build Step guide for more scripts and the pitfalls that make it build anyway.

Trade-offs. No preview for those branches means nothing to click in review. When a bot pull request needs a preview, push from a branch with another name, or build it by hand.

In Deploy Center

The ignore step only cuts previews. For production, Deploy Center turns off auto-deploy so many pushes become one deploy, and the Claude Code plugin and the MCP server let an agent see what is waiting without deploying it. See stop Vercel building every push.

Questions

Which exit code skips a build?

Exit 0 skips the build. Exit 1 lets it run.

Does this stop production builds?

No. It skips only the branches you list. Production and branches from people still build.

How do I skip one commit by hand?

Check VERCEL_GIT_COMMIT_MESSAGE for a marker such as [skip deploy] in the Ignored Build Step.

Does it work in a monorepo?

The step runs per project. To skip projects a commit did not touch, see the guide on stopping Vercel building every push.
