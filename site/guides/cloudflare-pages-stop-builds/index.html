How to stop Cloudflare Pages building on every push

In the Pages project open Settings → Builds & deployments and set Production deployments and Preview deployments to off (none). A push then builds nothing and no longer uses one of your monthly builds. Deploy by hand when you want to ship.

Last updated 16 November 2026 · by Patrick Schmetzer, author of Deploy Center

Cloudflare does not charge per build. Pages plans have a build count limit, and every push to a connected repository, and every push to a preview branch, uses one build. Pushing often does not cost more money, but it uses up the quota and builds queue behind each other.

1. In the dashboard

  1. Open Workers & Pages, then your project, then Settings → Builds & deployments.
  2. Choose Configure Production deployments and turn automatic production deployments off.
  3. Choose Configure Preview deployments and set them to none.

Trade-offs. No push builds anything, preview deployments per pull request included. A project made by direct upload (wrangler) has no Git connection, so pushes never build it and there is nothing to turn off.

2. Deploying afterwards

Whether Cloudflare builds a deployment you create by hand while production deployments are off is not documented. It may build, or it may create a deployment that is skipped. Check with one real build before you rely on it, and keep an eye on the deployment's stage the first time.

Cloudflare Pages in Deploy Center

Deploy Center supports Cloudflare Pages as an opt-in host: deploys providers enable cloudflare, then pbpaste | deploys cloudflare set-key with an API token that has Cloudflare Pages: Edit. deploys cloudflare off <project> sets both switches off and remembers what they were, deploys cloudflare selftest <project> --yes runs the one real build described above, and deploys cloudflare deploy <project> deploys the newest commit of the production branch. deploys cloudflare on <project> puts the old values back. Details: the Cloudflare Pages provider docs.

Questions

Does Cloudflare charge for each build?

No. Pages plans have a build count limit per month instead. Every push to a connected repository uses one build, and so does each preview branch push.

Which settings stop push builds?

Production deployments and Preview deployments under Settings, Builds and deployments. Both have to be off for a push to build nothing.

Do direct upload projects build on push?

No. A project made by direct upload with wrangler has no Git connection, so pushes never build it.

Does Deploy Center support Cloudflare Pages?

Yes, as an opt-in host: deploys providers enable cloudflare. It turns both switches off, remembers their old values, and can turn them back on.
