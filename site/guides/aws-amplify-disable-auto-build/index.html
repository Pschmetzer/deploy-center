How to disable AWS Amplify auto-build for a branch

Run aws amplify update-branch --app-id <id> --branch-name main --no-enable-auto-build. Pushes to that branch then no longer start a build. Start one yourself with aws amplify start-job --job-type RELEASE. Other branches keep their own setting.

Last updated 20 November 2026 · by Patrick Schmetzer, author of Deploy Center

Amplify Hosting bills build minutes. On a Git-connected branch with auto-build on, every push builds. Check the current price per build minute on the AWS Amplify pricing page; what matters is that a branch pushed twenty times a day builds twenty times.

1. Turn auto-build off for a branch

aws amplify update-branch --app-id APP_ID --branch-name main --no-enable-auto-build

Do the same for each branch that builds on push. The app also has a setting that auto-builds branches Amplify creates later:

aws amplify update-app --app-id APP_ID --no-enable-branch-auto-build

2. Start a build yourself

aws amplify start-job --app-id APP_ID --branch-name main --job-type RELEASE

A RELEASE job builds the newest commit of the branch, and it works the same with auto-build off.

Trade-offs. Pull request previews are a separate setting (enablePullRequestPreview). They build only when a pull request is opened or updated, and you switch them off in the Amplify console. Apps deployed by upload have no Git connection and nothing to turn off.

AWS Amplify in Deploy Center

Deploy Center supports Amplify as an opt-in host. It calls the aws CLI, so it never holds an AWS key: echo my-profile | deploys amplify set-key stores a profile name, deploys amplify off <app> runs the command above for the production branch (--all for the other branches and the new-branch setting), and deploys amplify deploy <app> starts the RELEASE job. deploys amplify on <app> turns it back on. Only apps in one region are listed at a time. Details: the AWS Amplify provider docs.

Questions

Which command turns off Amplify auto-build?

aws amplify update-branch with --no-enable-auto-build, once per branch. update-app with --no-enable-branch-auto-build covers branches created later.

How do I start an Amplify build by hand?

aws amplify start-job with --job-type RELEASE builds the newest commit of the branch. It works with auto-build off.

Do pull request previews still build?

Yes, if enablePullRequestPreview is on. That is a separate setting.

Does Deploy Center support AWS Amplify?

Yes, as an opt-in host. It uses the aws CLI and a profile name, so it never stores an AWS key.
