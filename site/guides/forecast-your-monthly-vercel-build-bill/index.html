Forecast this month's Vercel build bill

Run deploys forecast. It reads what Vercel billed so far this month, divides by the days gone, projects to the end of the month, splits the spend by how often each project deployed, and warns when the projection nears the budget you set with deploys budget set.

Last updated 26 November 2026 · by Patrick Schmetzer, author of Deploy Center

A build bill is a surprise because it arrives after the month. The projection is simple: if the first ten days of a 30-day month cost $12, the month ends near $36. deploys forecast does that sum for you and shows which projects drive it. It is an estimate, and says so.

1. Set a budget

The budget is the number the forecast compares against. It is stored on your Mac.

deploys budget set 50

2. Run the forecast

deploys forecast
deploys forecast --warn 70   # warn from 70 % of the budget
deploys forecast --json

The output looks like this (made-up numbers):

Forecast for 2026-11 (day 10 of 30), an estimate
  Spent so far: $12
  End of month: about $36 of the $50 budget
  Per project (deploys this month, share of the spend by deploys):
    vercel/example-web: 31 deploys, about $24.19
    vercel/example-api: 9 deploys, about $7.02

A warning appears from 80 percent of the budget by default (--warn changes that), and the command exits with 1 when the projection is over the budget, so a scheduled job or a CI step can fail on it.

3. Read it for what it is

The spend comes from Vercel's billing; the split per project comes from the deploy journal on your Mac, so only deploys made through Deploy Center count there. Render has no billing API, so its projects only show deploy counts. Early in a month the projection is rough, and a single large build moves it a lot.

Trade-offs. The forecast shows the trend, not an invoice. For the exact figure, use the host's usage page. To act on the trend, turn off the builds nobody needs first: disable Vercel auto-deploy.

Questions

Is the forecast the real bill?

No. It projects the month from the spend so far. A large build late in the month moves it, and the split per project is an estimate.

Does it work for Render or Netlify?

Only the Vercel spend is read. Render has no billing API here, so its projects show deploy counts without dollars.

Can a script use it?

Yes. deploys forecast --json prints the numbers, and the exit code is 1 when the projection is over the budget.

Where does the budget come from?

From deploys budget set, for example deploys budget set 50. Without a budget the forecast still runs and says none is set.
