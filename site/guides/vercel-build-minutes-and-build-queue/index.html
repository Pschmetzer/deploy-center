Vercel build minutes and the build queue: why many pushes cost and wait

Build minutes are the number of builds multiplied by how long each takes. Every push builds every connected project, so the count grows with pushes, projects and branches, not with releases. Measure it, then cut builds before you tune build time.

Last updated 16 November 2026 · by Patrick Schmetzer, author of Deploy Center

A push does not build one thing. Vercel builds every project connected to the repository, production on the production branch and a preview on every other branch. Builds that do not fit into what your plan runs at once wait in a queue, so many pushes also mean waiting. The limits depend on your plan: read them on Vercel's pricing page instead of trusting a number from a blog.

1. Count the builds

Builds a month = pushes a day × projects that build from the repository × working days. Minutes = builds × the minutes one build takes. Cost = minutes × your price per build minute, which is on your Vercel usage page. Three projects, twenty pushes a day, twenty working days is 1,200 builds before a single bot branch.

2. Measure with your own numbers

deploys costs 14        # Vercel charges per day for the last 14 days
deploys simulate        # an estimate: auto-deploy for a month against one deploy a day

Both are estimates and say so. The build cost calculator does the same sum in the browser with the numbers you type in.

3. Cut builds first, then build time

  1. Skip previews nobody looks at: bot and agent branches.
  2. Skip projects a commit did not touch in a monorepo: stop Vercel building every push.
  3. Turn off auto-deploy for production and deploy once when you are ready: disable Vercel auto-deploy.

A build that is skipped never reaches the build command. Faster builds help after that, but every build you remove is a build that never queues.

Trade-offs. Fewer builds mean fewer preview links in review and a fix that is not live until you deploy it. Keep previews where people review.

Questions

How do build minutes add up?

Builds multiplied by how long each takes. Every push builds every connected project, so pushes, projects and branches drive the count.

Where do I find my price per build minute?

On your Vercel usage page. Deploy Center takes it from the billing data where it can, or from deploys price set.

Does a skipped build cost money?

A skipped build is cancelled before the build command runs. Check your usage page to see how your plan counts it.

Are the numbers from deploys costs and simulate exact?

costs reads what Vercel charged per day. simulate and the ledger are estimates and are marked as such.
