Find TLS certificates that run out soon

deploys certs checks the TLS certificate of every project's address, and of the platform's own domain too, and exits with 1 when one runs out within the number of days you set. A host it cannot reach is unknown, not a failure.

Last updated 23 November 2026 · by Patrick Schmetzer, author of Deploy Center

Deutsche Fassung

1. Run it

deploys certs                 # warn when a certificate ends within 14 days
deploys certs --days 30
deploys certs --json

It asks each address once and reads the certificate. It does not deploy, change or renew anything.

2. Use the exit code

The exit code is 0 when nothing ends soon and 1 when a certificate does. That fits a scheduler, a CI job or a pre-deploy step:

deploys certs --days 21 || echo "a certificate ends within 21 days"

Put it in a weekly job and send the failure to the chat you already read. Hosts such as Vercel, Netlify and Render renew their own certificates. A custom domain with its own certificate, or a DNS record that points elsewhere, is what usually runs out.

3. Unknown is not failed

A host that does not answer (DNS, refused, timeout) shows as unknown. That does not set the exit code to 1, so a project that is offline does not wake you at night. Look at the unknown ones yourself, they are often a retired project. deploys ignore <project> leaves such a project out.

4. Check one deploy too

After a deploy, deploys verify can check the certificate in the same run, see roll back automatically:

deploys verify web --cert-days 14

Questions

Does deploys certs start a deploy?

No. It reads the certificates and prints. Nothing starts a build, a deploy or a rollback without a click or a command with --yes.

Which addresses does it check?

The address of every project that Deploy Center knows, and the platform's own domain for it.

Why is a project unknown?

The host did not answer: DNS, a refused connection or a timeout. It is not counted as a failure.

Can I get it as JSON?

Yes. deploys certs --json prints one JSON value for a script.
