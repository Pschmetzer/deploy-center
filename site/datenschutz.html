Die App Deploy Center

Die App sendet keine Telemetrie und hat kein Konto bei uns; es gibt keinen Server von uns. Sie spricht mit Ihren eigenen Zugängen direkt mit Vercel, Render und GitHub, ruft für Logos und die Prüfung nach einem Deploy Ihre eigenen Websites auf und fragt einmal am Tag die Release-Seite auf GitHub ab, ob es eine neue Version gibt (in den Einstellungen abschaltbar). Wenn Sie ein Update installieren, lädt die App es von GitHub herunter. Ihr Render-API-Key liegt nur im Schlüsselbund Ihres Macs. Fehler werden nur lokal in ~/Library/Logs/DeployCenter.log gespeichert.
